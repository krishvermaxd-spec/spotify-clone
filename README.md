# Spotify Clone

A Spotify web player clone built with HTML, CSS and JavaScript.

## Screenshots
![Home](screenshots/homepage.png)
![Home](screenshots/mobile-display.png)

## Features
- Song playlist with play and pause
- Seek bar and song info
- Responsive layout

## Built with
- HTML
- CSS
- JavaScript

## Run it locally
Download the repo and open `index.html` in your browser.
